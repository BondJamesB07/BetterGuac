  • These are the settings most servers need: host, port, username and password.
  • SSH key file: the full path to the private key file on the BetterGuac server, like /etc/betterguac/keys/web-01. Don't paste the key itself. The file must be in /etc/betterguac/keys, owned by root with group tomcat and mode 640. The key is read from the file each time someone opens the server, so it never goes into the database or the browser. If the key has a passphrase, set it under "Show all settings".
  • Leave the port empty for the usual port of that type (SSH 22, RDP 3389, VNC 5900).
  • Groups: one or more names separated by commas, like Proxmox, database. A new name creates the group. Anyone who's a member of one of these groups can open this server.
  • For RDP, the domain, security mode and "ignore certificate" are here too.
  • "Show all settings" opens every Guacamole option for this server.
  • Under Assigned to, tick the users who can open this server. Those ticks save right away. Admins can open every server anyway.
